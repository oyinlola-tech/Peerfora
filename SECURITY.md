# Security policy

Peerfora is pre-launch. Do not submit real student, credential, or eligibility data to local development builds.

Report suspected vulnerabilities privately to the repository owner. Do not publish exploit details before an agreed fix is available.

The API's implemented security controls and open limitations are tracked in [the security notes](docs/security/threat-model.md) and [production readiness](docs/deployment/production-readiness.md). These documents are not a claim of a completed security audit.
